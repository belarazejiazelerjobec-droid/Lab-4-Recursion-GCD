# Laboratory 4 - Recursion GCD

## Description: 
a application that calculates the Greatest Common Divisor (GCD) of two non-negative integers using a recursive implementation of the Euclidean algorithm. The application prints a live execution trace.

## Language & Tools Used
Java
Online Compiler (OnlineGDB)

## How to Run the Program
1. Open the `GCDProgram.java` file in an online editor like OnlineGDB or Programiz.
2. Click the green **Run** button at the top of the screen.
3. Input your numbers into the console prompt at the bottom.
